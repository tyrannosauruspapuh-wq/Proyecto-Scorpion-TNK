Integrante 1: "Buenos días, tardes, noches o cualquier momento en el que estén viendo este vídeo, bienvenidos profesores y compañeros. Hoy les vamos a presentar nuestro proyecto final: un Sistema de Control Inalámbrico para un Tanque Robótico, diseñado y procesado íntegramente en hardware a través de un dispositivo de lógica programable MAX II de Altera. El objetivo principal de este circuito es permitir el control total de un chasis móvil de orugas de forma inalámbrica. El usuario interactúa con el tanque a través de una aplicación móvil que replica exactamente la distribución y los comandos de un mando de Xbox vía Bluetooth. El sistema procesa órdenes de movimiento traccional —como avanzar, retroceder y girar— y controla de forma paralela la posición de dos servomotores para la orientación de una cámara o herramienta. Además, el tanque cuenta con un Escudo de Emergencia Ultrasónico autónomo; si el tanque detecta un obstáculo al frente, ignora la orden del usuario y se clava en seco para evitar una colisión en tiempo real, les hbalaremos más de esto en unos instantantes, así que sigan viendo. :D"
